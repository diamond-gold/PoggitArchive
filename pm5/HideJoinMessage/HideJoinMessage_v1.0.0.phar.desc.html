HideJoinMessage lets you hide or replace the default join and leave messages on your server. You can set custom messages with the {player} placeholder, send a private welcome message only the joining player sees, and configure an op exception so specific players still show their messages.

Features:

  • Hide join and leave messages independently
  • Custom message support with {player} placeholder
  • Private welcome message for the joining player
  • Op exception via permission
  • /hj reload to reload config in-game
