KillEffects

A simple PocketMine-MP plugin that rewards players with potion effects after eliminating another player. Features

Speed II on kill Regeneration I on kill Lightweight and simple Supports PocketMine API 5 Perfect for PvP servers and SMPs

Effects Speed II for 1 minute Regeneration I for 1 minute

Compatibility

PocketMine-MP API 5 Minecraft Bedrock 1.20+
