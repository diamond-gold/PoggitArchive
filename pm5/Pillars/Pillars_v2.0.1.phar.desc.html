General

Pillars of Fortune is an exciting Minecraft Bedrock minigame plugin for PocketMine-MP. Players fight to be the last one standing across dynamically created and reset game worlds. Developed by TheWindows and Doma (v2.0.0).

Quick Start Guide (for admins)

  1. Use /pillars admin → Create Game, enter the world name and settings.
  2. Use the Spawn Wand (Blaze Rod) to set spawn points by right‑clicking blocks.
  3. Create NPCs with /pillars npc create so players can open the game menu by hitting them.
  4. (Optional) Customize scoreboard lines and database (JSON/MySQL) in config.yml.
  5. Players join with /pillars join [map] or by using NPCs.

The lobby world name defaults to world – change it in config.yml if needed.

Features

  • Interactive UI – Powered by FormAPI: join, spectate, view stats, and access the market.
  • Scoreboard Integration – Fully customizable lines with placeholders for lobby, waiting, game, and spectator states.
  • Boss Bar Support – Shows item drop countdowns during games (uses apibossbar virion).
  • NPC Management – Admins can create, list, and remove NPCs that open the game menu when hit.
  • Spectator System – Spectate active games from the lobby or after dying, with a compass to teleport to alive players.
  • Flexible Commands – Short aliases (/p) for quick access.
  • JSON & MySQL Support – Choose your database provider in config.yml (JSON fallback if MySQL fails).

Commands

Player Commands (permission: pillars.join, default: true)

Command Description
/pillars Open the game menu
/pillars join [map] Join a specific game or open the game menu
/pillars leave Leave the current game
/pillars list List all active games with player counts and status
/pillars stats View your personal stats
/pillars info Show plugin version, authors, and active game count

Admin Commands (permission: pillars.admin, default: op)

Command Description
/pillars admin Open the admin settings menu
/pillars npc create Spawn an NPC at your location
/pillars npc list List all NPCs with positions
/pillars npc remove <id> Remove an NPC by index
/pillars npc removeall Remove all NPCs
/pillars reset <map|all> Reset a map or all maps to their original state

Alias: /p – e.g. /p j for join, /p l for leave.

Permissions

Permission Description Default
pillars.join Access to basic player commands true
pillars.admin Access to admin commands op

Map Setup

  1. Build your map and place it in the server worlds/ folder.
  2. Run /pillars admin → Create Game, enter the world name and settings.
  3. Use the Spawn Wand (Blaze Rod) to place spawn points by right‑clicking blocks.
  4. The map is automatically saved as a template and restored after every game.

Scoreboard Placeholders

Configure scoreboard lines in config.yml using these placeholders:

{player_name} {player_coins} {player_wins} {player_kills} {player_deaths} {player_kdr} {online_players} {game_id} {game_players} {game_max_players} {game_min_players} {game_time_left} {date} {time}
