CherrySapling is a simple plugin that adds cherry saplings to your server, allowing them to grow naturally like vanilla trees.

Features

  • Adds cherry saplings into the game
  • Natural growth like default Minecraft trees
  • Lightweight and optimized
  • Easy to use, no configuration needed

Installation

  1. Download the plugin
  2. Place it into the plugins/ folder
  3. Restart your server

Usage

  • Get cherry saplings in-game
  • Plant them like normal saplings
  • They will grow naturally over time

Requirements

  • PocketMine-MP 5.x.x
