• Add migration, SQLite & new friend features
    • Bump plugin to v2.0.0 and introduce data migration and SQLite support. Adds new permission friendsx.migrate and documents sqlite storage in config (plugin will import data/friends_v2.json when switching). Adds new friend commands/arguments (migrate, msg, status, top), messaging, status, favorites/groups, top-list, UI enhancements (search, pagination, confirm dialogs, group selector) and many new translation keys across languages. Implements SQLiteProvider, MigrationManager, FriendsMetadataManager, PlayerStatusManager and other manager/form updates; updates JSONProvider and various command handlers/forms to support new features.
